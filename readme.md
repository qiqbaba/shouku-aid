**收库助手** 是一款专为 **[收库123导航网 (shouku123.com)](http://shouku123.com/)** 打造的高效链接可用性检测油猴脚本。它能帮助您快速找出页面中所有的死链、异常链接，并支持一键后台批量打开、一键导出复制与快速定位，极大地提升了日常链接维护与清理的工作效率。

## ✨ 核心特色

*   **🛡️ 绕过 CORS 跨域限制**：利用 Tampermonkey 内置的跨域请求能力（`GM_xmlhttpRequest`），无需配置后端代理，直接在前端即可准确检测各种第三方站点的连通性。
*   **💾 检测结果持久化（刷新不丢失）**：内置 2 小时本地缓存机制。即使您在修改完某个失效链接后**刷新了网页，之前的检测状态依然会被自动载入**，避免了重复检测的麻烦。
*   **🕐 检测时间记录**：每个链接的检测完成时间会被精确记录（精确到秒），悬停在状态小圆点上即可查看；控制面板底部还会以不显眼的小字显示最近一次检测完成的时间，方便您判断结果的新鲜程度。
*   **🔥 链接热度显式呈现**：自动提取导航页各个链接内置的热度数值，并以精致的亮橙色胶囊标签（如 `🔥 3.3w` / `🔥 850`）直观呈现。借助 **CSS Flexbox 弹性自适应布局**，即使用户链接标题极长（如被 `...` 截断），状态小圆点与热度标签**仍会 100% 完整显示在最右侧**，绝不被溢出裁剪。
*   **🔮 现代暗色玻璃拟态 UI 与整站暗色模式**：精致的高清毛玻璃控制面板，支持**任意拖拽移动**（自动记忆位置）以及**一键折叠收起**为迷你悬浮球。面板具备视口自适应与内部极简滚动保护，并支持一键开启整站护眼暗色模式。
*   **🚀 批量后台静默打开**：支持自定义每次打开的数量，一键批量在后台打开所有失效/异常链接。结合已打开标记，助您快速进入对应后台修改链接。
*   **📋 异常清单一键复制 & 🎯 定位跳转**：一键将当前所有异常/失效链接的名称与 URL 复制到剪贴板，并支持平滑滚动定位到下一个异常链接处并伴随高亮闪烁提示。
*   **📁 板块网址一键导出与浏览器书签生成**：在“其他设置”中支持一键导出**当前板块**或**所有板块**（全站跨板块无感异步抓取）的网址数据，支持 **TXT 文本（层级排版）**、**纯网址 (URL 列表)**、**HTML 浏览器标准书签（可直接导入 Chrome / Edge / Firefox）**、**JSON 结构数据**及 **CSV 表格（UTF-8 BOM 防乱码）**，支持一键下载文件或复制至剪贴板。
*   **🚦 彩色呼吸灯状态标识**：在网页链接后方即时生成状态标识小圆点，状态一目了然：
    *   ⚪ **灰色**：等待检测
    *   🔵 **闪烁蓝**：正在检测中
    *   🟢 **绿色**：正常访问 (`2xx` 状态码)
    *   🟡 **黄色**：页面异常 (`4xx` / `5xx` 状态码)
    *   🟠 **橙色**：被 Cloudflare 限流 (`HTTP 429`，网站实际存活)
    *   🌐 **天蓝色**：GitHub 访问异常 (国内网络受限/波动或连接超时，不代表仓库失效)
    *   🔴 **闪烁红**：彻底失效 (连接超时、拒绝访问或 DNS 解析失败)

## 🛠️ 功能概览

1.  **多线程并发检测**：支持自定义并发数（1~10 线程），且在检测过程中可随时拖动滑块实时调节速度。主控按钮与进度条紧凑排列在顶部，反馈直观连贯。
2.  **7 种真实状态看板与彩色指示**：7 种具备实际筛选功能的状态卡片规整排列，每个状态配有对应色彩指示圆点与选中光晕；“总链接”转为在顶部标题徽章与进度详情中直观呈现，分类看板纯粹易用。
3.  **🔍 实时关键词搜索**：面板内置即时搜索框，输入关键词即可毫秒级动态过滤网页中的链接（同时匹配网站名称、链接 URL、状态详情及气泡说明），支持一键清空与 ESC 快捷重置。
4.  **快捷多维筛选**：
    *   提供「**仅看异常**」一键快捷筛选（自动选中异常、失效、CF 限流与 GitHub 异常）。
    *   保留「**全选**」与「**取消**」一键重置筛选。
    *   独立的「**⧉ 重复**」胶囊过滤标签，快速筛选出重复收录的网址。
5.  **智能批量打开与实用处理工具**：
    *   自定义每次点击批量打开的链接数量，优先使用油猴 `GM_openInTab` 在后台静默打开。
    *   **📋 复制异常**：一键将所有死链/异常链接汇总为格式化文本复制至剪贴板，并弹出暗色 Toast 提示。
    *   **🎯 定位异常**：点击自动平滑居中滚动至页面下一个异常链接处，并伴随红黄色闪烁高亮。
6.  **⚙️ 手风琴折叠“其他设置”与网址导出**：
    *   低频设置项（链接热度显隐、整站暗色模式、热度阈值过滤、网址导出）收纳于手风琴折叠卡片中，默认收起，面板紧凑轻盈。
    *   **热度阈值即时生效**：数值输入支持 300ms 防抖即时生效，无须手动点击确定。
    *   **多板块网址导出**：可选导出当前板块或所有板块，支持 TXT / URL / HTML 书签 / JSON / CSV 5 种格式，一键下载或复制到剪贴板。
7.  **折叠悬浮球感知强化**：
    *   **检测中呼吸光环**：后台检测时，悬浮球外圈展示蓝色动态脉冲光环。
    *   **未读异常红色角标**：检测完成后，若存在异常链接，悬浮球右上角自动显示未处理数量徽标（如 `🔴 3`）。
8.  **小屏视口保护与滚动**：面板设置 `max-height: calc(100vh - 40px)` 与极简暗色细滚动条，彻底解决笔记本小屏幕或高缩放下底部溢出无法点击的问题。

## 📖 使用说明

1.  安装本脚本后，打开 [收库123导航页](http://shouku123.com/)。
2.  页面右侧将自动出现 **⚡ 收库助手** 面板。
3.  点击 **开始检测**，脚本将自动获取当前页面的所有链接并开始并行探测。
4.  若面板挡住内容，可拖动面板顶部进行移动，或者点击 **➖** 按钮将其收起为右侧的 🔗 悬浮球。
5.  检测完成后，可通过 **搜索框输入关键词** 或点击 **"仅看异常"** / 状态卡片筛选链接，配合 **"打开异常/失效网站"**、**"📋 复制异常"** 或 **"🎯 定位异常"** 进行快速核对与修改。
6.  在 **⚙️ 其他设置** 中，可选择导出当前板块或全部板块的网址，快速生成浏览器书签文件、TXT 清单、CSV 表格或 JSON 结构数据。

---

## ⚙️ 脚本配置信息

*   **支持的匹配域名**：`shouku123.com` 以及 `www.shouku123.com`
*   **需要的油猴权限**：
    *   `GM_xmlhttpRequest` (用于安全绕过跨域限制进行链接探测与多板块数据抓取)
    *   `GM_openInTab` (用于后台静默批量打开网页)
    *   `GM_setClipboard` (用于一键复制异常链接与导出数据到剪贴板)

---

## 📝 提示与声明

> [!TIP]
> 默认的检测超时时间为 6 秒。如果检测时因对方网站服务器短暂波动导致误报，可点击“重置”并调低并发数重新检测。

> [!NOTE]
> 本工具仅供网页管理员或个人用于链接可用性维护排查，请合理设置并发请求数，避免对目标站点造成不必要的请求压力。
